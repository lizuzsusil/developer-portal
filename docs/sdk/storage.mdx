# Storage (`sdk.storage`)

Host-backed key/value store. `get`/`set` move raw strings; `getJson`/`setJson` layer transparent JSON on top of the same wire; `scoped(prefix)` namespaces keys per feature (`prefix:key`, nestable); `getMany`/`getManyJson` batch reads in one RPC round trip.

---

## Public Methods

### `get(key)` / `set(key, value, options?)` / `remove(key)`

Raw-string CRUD. `get` resolves `null` when unset.

**Signatures:**

```typescript
get(key: string): Promise<string | null>;
set(key: string, value: string, options?: StorageSetOptions): Promise<void>;
remove(key: string): Promise<void>;
```

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `key` | `string` | Yes | - | Storage key. |
| `value` | `string` | Yes | - | Raw string to store. |
| `options.ttlMs` | `number` | No | - | Time-to-live in ms. Best-effort: a host that honors it drops the value after expiry (later `get` → `null`); others store without expiry. |

<CodeTabs
  typescript={`await sdk.storage.set("draft:-return-2026", "in-progress", { ttlMs: 86_400_000 });
const draft = await sdk.storage.get("draft:return-2026");`}
  javascript={`await sdk.storage.set("draft:-return-2026", "in-progress", { ttlMs: 86_400_000 });
const draft = await sdk.storage.get("draft:return-2026");`}
/>

### `getJson(key)` / `setJson(key, value, options?)`

JSON convenience over the same wire. `getJson` resolves `null` when unset **or** when the stored string isn't valid JSON.

**Signatures:**

```typescript
getJson<T = unknown>(key: string): Promise<T | null>;
setJson(key: string, value: unknown, options?: StorageSetOptions): Promise<void>;
```

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `key` | `string` | Yes | - | Storage key |
| `value` | `unknown` | Yes | - | Value to serialize as JSON |
| `options.ttlMs` | `number` | No | - | Time-to-live in ms |

<CodeTabs
  typescript={`await sdk.storage.setJson("profile", { ward: 12, household: 4 });
const profile = await sdk.storage.getJson<{ ward: number }>("profile");`}
  javascript={`await sdk.storage.setJson("profile", { ward: 12, household: 4 });
const profile = await sdk.storage.getJson("profile");`}
/>

### `scoped(prefix)`

Returns a sub-module with every key prefixed (`prefix:key`). Nestable (`a.scoped("b").scoped("c")` → `a:b:c:key`); `remove`/`getMany` follow the same prefixing.

**Signature:** `scoped(prefix: string): StorageSdkModule`

<CodeTabs
  typescript={`const prefs = sdk.storage.scoped("prefs");
await prefs.set("theme", "dark");"`}
  javascript={`const prefs = sdk.storage.scoped("prefs");
await prefs.set("theme", "dark");"`}
/>

### `getMany(keys)` / `getManyJson(keys)`

Batch reads in a single RPC. Per-key failures resolve `null` rather than rejecting.

**Signatures:**

```typescript
getMany(keys: string[]): Promise<Array<string | null>>;
getManyJson<T = unknown>(keys: string[]): Promise<Array<T | null>>;
```

| Parameter | Type | Required | Description |
|---|---|---|---|
| `keys` | `string[]` | Yes | Array of storage keys to retrieve |

**Returns:** `Array<string | null>` or `Array<T | null>` - same order as input keys, `null` for missing/failed keys

<CodeTabs
  typescript={`const [draft, profile] = await sdk.storage.getMany(["draft", "profile"]);
// draft: string | null, profile: string | null

// With JSON
const [settings, prefs] = await sdk.storage.getManyJson<Settings>(["settings", "prefs"]);
// settings: Settings | null, prefs: Settings | null`}
  javascript={`const [draft, profile] = await sdk.storage.getMany(["draft", "profile"]);
// draft: string | null, profile: string | null

// With JSON
const [settings, prefs] = await sdk.storage.getManyJson(["settings", "prefs"]);
// settings: Settings | null, prefs: Settings | null`}
/>
