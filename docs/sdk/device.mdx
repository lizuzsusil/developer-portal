# Device Capabilities Module (`sdk.device`)

The `sdk.device` module grants mini apps access to native hardware sensors, camera, GPS location, gallery, contacts, file system, network info, and biometric authentication via host bridge guards.

---

## Device Permission Statuses

Every device call returns a result with a `status` field. The mini app must branch on it rather than assuming success:

| Status | Meaning | Required action |
| --- | --- | --- |
| `granted` | Permission granted; `data` is populated (e.g. `location`, `file`) | Use `res.data`. |
| `denied` | User denied permission | Show a retry affordance or a settings hint. |
| `permanentlyDenied` | Permission permanently denied / revoked | Direct user to device settings to re-enable it. |
| `restricted` | OS-level restriction (e.g. parental controls, MDM) | Inform the user that the device is restricted. |

`data` exists only on `granted`. Every tab (location, camera, gallery, files, download, contact, biometric) switches on `res.status` and maps each case to a distinct UI error message. A typical handler:

```typescript
const res = await sdk.device.location({ reason: "To view your current location" });
switch (res.status) {
  case "granted":
    setLocation(res.data ?? null);
    break;
  case "denied":
    setError("Location permission denied.");
    break;
  case "permanentlyDenied":
    setError("Please enable location permission from device settings.");
    break;
  case "restricted":
    setError("Location access is restricted on this device.");
    break;
}
```

> **Is a runtime needed to initialize the mini app?** No. Device capabilities are bridged by the host via `window.__GSA_SDK__`; the mini app bundle imports no runtime module. The `platform.runtime` constraint in the manifest is a host-side version check.

## Feature Detection

### `isSupported(action)`

Checks if a specific device action (e.g., `"location"`, `"biometric"`) is supported by the host shell.

```typescript
if (sdk.device.isSupported("biometric")) {
  // Offer fingerprint authentication
}
```

## Device Methods

### `location(options?)`

Requests device location coordinates. Options carry only `reason` - see the `status`-switch
pattern at the top of this page (never branch on a boolean):

```typescript
const loc = await sdk.device.location({ reason: "To view your current location" });
if (loc.status === "granted") {
  console.log("Latitude:", loc.data.latitude, "Longitude:", loc.data.longitude);
}
```

### `camera(options?)`

Triggers native camera capture.

```typescript
const result = await sdk.device.camera({ reason: "To capture a photo for verification" });
if (result.status === "granted") {
  const photoUrl = result.data.url;
}
```

### `gallery(options?)`

Opens system image picker.

```typescript
const photo = await sdk.device.gallery();
```

### `files(options?)`

Opens document picker.

```typescript
const file = await sdk.device.files();
```

### `download(options?)`

Downloads file to device filesystem.

```typescript
const res = await sdk.device.download({
  url: "https://sewa.gov.np/receipt.pdf",
  fileName: "tax_receipt.pdf",
});
```

### `contact(options?)`

Opens system contact selector.

```typescript
const contact = await sdk.device.contact();
```

### `biometric(options?)`

Triggers native TouchID / FaceID / Fingerprint prompt.

```typescript
const bio = await sdk.device.biometric({ reason: "Authorize payment" });
if (bio.status === "granted" && bio.data?.success) {
  // Proceed with authorized operation
}
```

### `network()`

Queries active network connection state.

```typescript
const net = await sdk.device.network();
console.log("Online:", net.online, "Type:", net.type);
```

### `info()`

Returns hardware, OS, and screen dimensions.

```typescript
const info = await sdk.device.info();
console.log(info.deviceModel, info.osVersion, info.screenWidth);
```

### `share(options)`

Opens the native share sheet.

```typescript
await sdk.device.share({ title: "Tax receipt", text: "Paid Rs. 1,500", url: "https://sewa.gov.np/receipt/123" });
```

### `clipboardWrite(text)` / `clipboardRead()`

```typescript
await sdk.device.clipboardWrite("Copied text");
const text = await sdk.device.clipboardRead();
```

### `haptics(style)`

Triggers haptic feedback. `style`: `light` | `medium` | `heavy` | `selection`.

```typescript
await sdk.device.haptics("light");
```

### `notifications(options?)`

Requests push-notification permission / token (device-scoped). For app-level push, use [`sdk.notifications`](/docs/sdk/notifications) instead.

### `review()` - reserved, not yet implemented

`review` is a reserved action name (app-store review dialog) but the SDK module exposes no
`review()` method yet - calling `sdk.device.review()` will fail. Guard with a `typeof` check and
treat it as upcoming:

```typescript
const maybeReview = (sdk.device as { review?: () => Promise<void> }).review;
if (typeof maybeReview === "function") {
  await maybeReview();
}
```
