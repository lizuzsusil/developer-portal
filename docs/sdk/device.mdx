# Device (`sdk.device`)

Bridges native hardware and OS services - location, camera, gallery, files, downloads, contacts, biometrics, notifications, network, device info, share, clipboard, haptics. Every privileged call returns a `{status, data?, error?}` envelope; branch on `status`, never assume success. Gate calls with `isSupported(action)` (action + `device` capability must both hold).

## Response envelope

| Field | Type | Description |
|---|---|---|
| `status` | `"granted" \| "denied" \| "permanentlyDenied" \| "restricted"` | Outcome - see statuses below. |
| `data` | `T?` | Populated **only** on `granted`. |
| `error` | `string?` | Human-readable reason on non-granted outcomes. |

| Status | Meaning | Required action |
|---|---|---|
| `granted` | Permission granted; `data` is populated | Use `res.data`. |
| `denied` | User denied permission | Show a retry affordance or settings hint. |
| `permanentlyDenied` | Permanently denied / revoked | Direct user to device settings. |
| `restricted` | OS-level restriction (parental controls, MDM) | Inform the user the device is restricted. |

switch (res.status) {
  case "granted": setLocation(res.data ?? null); break;
  case "denied": setError("Location permission denied."); break;

## Public Methods

### `isSupported(action)`

Whether a device action is available: the action must be known **and** the host must have negotiated the `device` capability.

**Signature:** `isSupported(action: DeviceAction): boolean`

| Parameter | Type | Required | Available values | Description |
|---|---|---|---|---|
| `action` | `DeviceAction` | Yes | `"location" \| "camera" \| "gallery" \| "files" \| "download" \| "contact" \| "biometric" \| "notifications" \| "network" \| "info" \| "share" \| "clipboard" \| "haptics" \| "review"` | Capability to probe. |

<CodeTabs
  typescript={`if (sdk.device.isSupported("biometric")) {
  // Offer fingerprint authentication
}`}
  javascript={`if (sdk.device.isSupported("biometric")) {
  // Offer fingerprint authentication
}`}
/>

### `location(options?)` / `camera(options?)` / `contact(options?)`

One-shot sensor reads. All take the same options and return a permission envelope.

**Signatures:**

```typescript
location(options?: DeviceExtraOptions): Promise<DevicePermissionBaseResponse<DeviceLocationResult>>;
camera(options?: DeviceExtraOptions): Promise<DevicePermissionBaseResponse<DeviceCameraResult>>;
contact(options?: DeviceExtraOptions): Promise<DevicePermissionBaseResponse<DeviceContactResult>>;
```

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `options.reason` | `string` | No | - | User-facing reason shown in the OS permission prompt. |

**Result payloads (`data` on `granted`):**

| Method | `data` fields |
|---|---|
| `location` | `{ latitude: number; longitude: number; accuracy?: number; timestamp?: Date \| string }` |
| `camera` | `{ url: string; fileName?: string; mimeType?: string; ... }` (see `DeviceCameraResult`) |
| `contact` | `{ contactName?: string; number?: string }` |

### `gallery(options?)` / `files(options?)`

Pick media/files from the device library.

**Signatures:**

```typescript
gallery(options?: DeviceFileOptions): Promise<DevicePermissionBaseResponse<DeviceGalleryResult>>;
files(options?: DeviceFileOptions): Promise<DevicePermissionBaseResponse<DeviceFileResult>>;
```

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `options.reason` | `string` | No | - | User-facing reason for the prompt. |
| `options.multiple` | `boolean` | No | `false` | Allow selecting more than one item. |
| `options.accept` | `string[]` | No | - | MIME/extension allowlist, e.g. `["image/*", ".pdf"]`. |

### `download(options?)`

Downloads a file to the device via the host.

**Signature:** `download(options?: DeviceDownloadOptions): Promise<DevicePermissionBaseResponse<DeviceDownloadResult>>`

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `options.url` | `string` | Yes | - | Source URL of the file. |
| `options.fileName` | `string` | Yes | - | Filename to save as. |
| `options.mimeType` | `string` | No | - | MIME hint, e.g. `"application/pdf"`. |
| `options.reason` | `string` | No | - | User-facing reason for the prompt. |

**Returns** `data.file: { url, fileName?, mimeType?, extension?, byteSize?, previewUrl? }` on `granted`.

### `biometric(options?)`

System biometric prompt (fingerprint / face).

**Signature:** `biometric(options?: DeviceBiometricOptions): Promise<DevicePermissionBaseResponse<DeviceBiometricResult>>`

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `options.reason` | `string` | No | - | Message shown in the biometric prompt. |
| `options[key]` | `unknown` | No | - | Extra host-specific knobs are passed through. |

**Returns** `data: { success: boolean; error?: string }` on `granted`.

### `notifications(options?)`

Device-level notification permission (distinct from push registration in `sdk.notifications`).

**Signature:** `notifications(options?: DeviceNotificationsOptions): Promise<DeviceNotificationResult>`

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `options.requestPermission` | `boolean` | No | - | Whether to prompt the user. Extra keys pass through. |

**Returns:** `{ enabled: boolean; token?: string }` (no permission envelope).

### `network()` / `info()`

Capability-free reads - no prompt, no envelope.

**Signatures:**

```typescript
network(): Promise<DeviceNetworkResult>;
info(): Promise<DeviceInfoResult>;
```

| Method | Returns |
|---|---|
| `network` | `{ online: boolean; type?: "wifi" \| "cellular" \| "none"; effectiveType?: string }` |
| `info` | `{ platform: "web" \| "flutter"; osVersion: string; appVersion: string; deviceModel?: string; screenWidth?: number; screenHeight?: number }` |

### `share(data)` / `clipboardWrite(text)` / `clipboardRead()` / `haptics(style?)`

Web-bridged utilities. All optional on the type (`share?`, …) - guard with `isSupported()` where the host may lack them.

**Signatures:**

```typescript
share?(data: { title?: string; text?: string; url?: string }): Promise<{ completed: boolean }>;
clipboardWrite?(text: string): Promise<void>;
clipboardRead?(): Promise<string>;
haptics?(style?: "light" | "medium" | "heavy" | "selection"): Promise<void>;
```

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `share().title` / `.text` / `.url` | `string` | No | - | At least one should be set. Resolves `{ completed }` (`false` on dismiss). |
| `clipboardWrite()` `text` | `string` | Yes | - | Text to place on the clipboard. |
| `haptics()` `style` | `"light" \| "medium" \| "heavy" \| "selection"` | No | `"light"` | Haptic intensity. |
