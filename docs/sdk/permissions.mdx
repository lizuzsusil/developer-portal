# Permissions Module (`sdk.permissions`)

Check what the citizen has allowed your mini app to do, before you try it.

---

## Public Methods

### `has(permission)`

Checks if a specific permission has been granted.

- **Signature**: `has(permission: string): Promise<boolean>`
- **Example**:

```typescript
const locationAllowed = await sdk.permissions.has("location");
if (locationAllowed) {
  // Access location API
}
```

### `list()`

Retrieves a list of all permissions currently granted to this mini app.

- **Signature**: `list(): Promise<string[]>`

```typescript
const permissions = await sdk.permissions.list();
console.log("Granted permissions:", permissions);
// Output: ["camera", "location", "storage"]
```
