# Platform (`sdk.platform`)

Reports which shell hosts the mini app. The `type` resolves during `sdk.initialize()` from the host's `platform.getType` reply (bare `"web"`/`"flutter"` string or a `{ type, appearance }` object that also hydrates locale/theme).

---

## Public Members

### `type`

The resolved host type. One of `"web"` or `"flutter"`.

**Signature:** `type: PlatformTypeLiteral`

### `isWeb()` / `isFlutter()` / `isMobile()`

Feature predicates derived from `type`. Note `isMobile()` is currently equivalent to `isFlutter()`.

**Signatures:**

```typescript
isWeb(): boolean;      // type === "web"
isFlutter(): boolean;  // type === "flutter"
isMobile(): boolean;   // type === "flutter"
```

### Usage Patterns

**Conditional device access:**

<CodeTabs
  typescript={`// On Flutter, use native device APIs
if (sdk.platform.isFlutter()) {
    const location = await sdk.device.location();
}`}
  javascript={`// On Flutter, use native device APIs
if (sdk.platform.isFlutter()) {
    const location = await sdk.device.location();
}`}
/>

**Platform-specific styling:**

<CodeTabs
  typescript={`if (sdk.platform.isMobile()) {
  document.body.classList.add("mobile-layout");
} else {
  document.body.classList.add("desktop-layout");
}`}
  javascript={`if (sdk.platform.isMobile()) {
  document.body.classList.add("mobile-layout");
} else {
  document.body.classList.add("desktop-layout");
}`}
/>

**Check platform type:**

  typescript={`const platformType: PlatformTypeLiteral = sdk.platform.type;

  javascript={`const platformType = sdk.platform.type;
console.log(\`Running on: \${platformType}\`);`}
/>
