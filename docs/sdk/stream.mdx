# Streaming

Long-lived responses use `StreamBuilder`, returned by [`sdk.api.request`](/docs/sdk/api) with `stream: true`. Chat SSE events and file bytes share this path - the mini app interprets the chunks either way.

## `StreamBuilder`

Created by the RPC layer per streamed request; chunks arrive ordered by `streamIndex`, and the host marks the final chunk with `streamLast: true`.

**Signature:** `request(method: string, params: ApiRequestParams & { stream: true }): Promise<StreamBuilder>`

| Member | Type | Description |
|---|---|---|
| `iterate()` | `AsyncIterable<string \| Uint8Array>` | Yields each chunk as it arrives. Never throws - iteration simply ends. |
| `waitUntilDone()` | `Promise<void>` | Resolves on clean completion; rejects with the terminal failure. |
| `cancel(err?)` | `void` | Stops consumption locally and notifies the host (`api.cancel`). |
| `isDone` | `boolean` | Whether the stream settled. |
| `isRejected` | `boolean` | Whether it settled with failure. |
| `receivedBytes` / `receivedChunks` | `number` | Totals observed so far. |
| `total` | `number \| null` | Expected chunks when the host declares `streamTotal`. |

```typescript
const builder = await sdk.api.request("GET", {
  endpoint: "/v1/tax-receipt",
  stream: true,
  signal: controller.signal,
});

for await (const chunk of builder.iterate()) {
  appendChunk(chunk); // string | Uint8Array, in order
}

await builder.waitUntilDone(); // throws only on terminal failure
```

Ordering is by `streamIndex`; retransmissions of an already-yielded index are dropped for live consumers. Streams are never retried automatically - re-issue the request to resume.

## Cancellation

Two ways to cancel:

| Mechanism | Call | Effect |
|---|---|---|
| `AbortSignal` (preferred) | `controller.abort()` | Rejects with `StreamCancelledError`, notifies host |
| Direct | `builder.cancel()` | Same - rejects locally, sends `api.cancel { requestId }` |

```typescript
const controller = new AbortController();
const builder = await sdk.api.request("GET", { endpoint, stream: true, signal: controller.signal });
controller.abort(); // or: builder.cancel();
```

## Wire

Stream frames are `PlatformMessage` with `type: "stream"`, `streamIndex`, `streamTotal`, and `streamLast`. See [Protocol](/docs/sdk/protocol).
