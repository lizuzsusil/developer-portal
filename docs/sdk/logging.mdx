# Logging & Dev Mode

> **Host-configured.** Logger, dev mode, and log level are set by the host when it constructs the
> SDK. Mini apps get the behavior for free; the only thing vendors need to know is the
> handler-leak warning below.

## Logger

The SDK logs through a `Logger` interface (`debug | info | warn | error`); the host wires a
console logger or a silencing no-op logger and picks the minimum level. There is nothing to
import or construct in a mini app.

## Dev Mode

The host may enable `devMode` (plus `logLevel: "debug"`), which turns on warnings for
unavailable capabilities (`"[dev] ... requires http capability"`). When unset, it defaults to
`process.env.NODE_ENV !== "production"` in the host build.

Handler-leak warning: >20 handlers on a single event emits a dev warning - unsubscribe (or pass
an `AbortSignal`) when your component unmounts.

## `validateSdkOptions`

Host-side helper that throws with details on a malformed SDK config (e.g. empty `miniAppId`).
Not called from mini apps.
