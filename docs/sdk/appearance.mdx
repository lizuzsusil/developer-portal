# Appearance (`sdk.appearance`)

Reads host-driven locale and theme. The host owns appearance - the mini app observes it and renders accordingly. Values hydrate during `sdk.initialize()` (from the `platform.getType` hint when the host sends one), then stay live via events.

---

## Public Methods

### `getLocale()`

Reads the host's active locale.

**Signature:** `getLocale(): Promise<LocaleState>`

**Returns:** `LocaleState`

| Field | Type | Description |
|---|---|---|
| `locale` | `string` | Full tag, e.g. `"en-LK"`, `"si-LK"`, `"ta-LK"`. |
| `language` | `string` | Primary subtag, e.g. `"en"`, `"si"`, `"ta"`. |
| `region` | `string?` | Region subtag, e.g. `"LK"`. |
| `direction` | `"ltr" \| "rtl"` | Resolved text direction for the locale. |

### `getTheme()`

Reads the host's active theme (preference + resolved mode).

**Signature:** `getTheme(): Promise<ThemeState>`

**Returns:** `ThemeState`

| Field | Type | Available values | Description |
|---|---|---|---|
| `preference` | `"light" \| "dark" \| "system"` | - | User-selected preference. |
| `mode` | `"light" \| "dark"` | - | Mode actually applied (`system` is resolved via media query). |

### `state()`

Synchronous snapshot of the current locale + theme. Never blocks - use it in render paths.

**Signature:** `state(): AppearanceState` (`{ locale: LocaleState; theme: ThemeState }`)

### `subscribe(listener)`

Subscribes to `appearance.locale.changed` / `appearance.theme.changed`. Returns an unsubscribe function.

**Signature:** `subscribe(listener: (state: AppearanceState) => void): () => void`

| Parameter | Type | Required | Description |
|---|---|---|---|
| `listener` | `(state: AppearanceState) => void` | Yes | Callback invoked on locale/theme changes |

**Returns:** `() => void` - unsubscribe function
