# Appearance Module (`sdk.appearance`)

Follow the citizen's language and light or dark preference. They chose it once in
Sewa; your mini app should match without asking again.

---

## Public Methods

### `getTheme()`

Fetches the active theme state.

- **Signature**: `getTheme(): Promise<ThemeState>`

```typescript
const themeState = await sdk.appearance.getTheme();
console.log("Preference:", themeState.preference); // "system" | "light" | "dark"
console.log("Active Mode:", themeState.mode);       // "light" | "dark"
```

### `getLocale()`

Fetches the active locale state.

- **Signature**: `getLocale(): Promise<LocaleState>`

```typescript
const localeState = await sdk.appearance.getLocale();
console.log("Locale Tag:", localeState.locale);   // e.g. "ne-NP"
console.log("Language:", localeState.language);     // e.g. "ne"
console.log("Direction:", localeState.direction);   // "ltr" | "rtl"
```

### `state()`

Returns a synchronous snapshot of the appearance store.

- **Signature**: `state(): AppearanceState`

### `subscribe(listener)`

Subscribes to host appearance state updates.

- **Signature**: `subscribe(listener: (next: AppearanceState) => void): () => void`

```typescript
const unsubscribe = sdk.appearance.subscribe((nextState) => {
  document.documentElement.classList.toggle("dark", nextState.theme.mode === "dark");
});
```

## Languages you are expected to support

Sewa ships in **Sinhala, Tamil and English**, and the citizen chooses. Your mini
app is expected to follow that choice rather than impose its own.

```js
const { locale } = sdk.appearance.state();
// "si-LK" | "ta-LK" | "en-GB"

i18n.changeLanguage(locale.language);   // "si" | "ta" | "en"
```

Subscribe, because the citizen can change it while your app is open:

```js
const stop = sdk.appearance.subscribe((next) => {
  i18n.changeLanguage(next.locale.language);
});
```

Do not build your own language switcher. Two switches that disagree is worse
than one you do not control.

Sinhala and Tamil are both left to right, but they set taller than Latin text.
Give headings and buttons room to grow rather than fixing their height.

## Following the theme

```js
sdk.appearance.subscribe((next) => {
  document.documentElement.classList.toggle("dark", next.theme.mode === "dark");
});
```

`theme.preference` is what the citizen chose, including `"system"`.
`theme.mode` is what it resolves to right now — that is the one to render with.
