# Navigation Module (`sdk.navigation`)

Move the citizen between screens, and keep your own router in step with Sewa's
back button. Get this right and back behaves the way the citizen expects; get it
wrong and they get stuck.

### `getCurrent()`

Queries current navigation state from the host.

- **Signature**: `getCurrent(): Promise<NavigationState>`

```typescript
const navState = await sdk.navigation.getCurrent();
console.log("Current Route:", navState.route);
```

### `router.back(consumed)`

Reports whether the mini app internal router handled a back-press or wants the host to exit the mini app container.

- **Signature**: `router.back(consumed?: boolean): Promise<NavigationRouterResult>`

```typescript
sdk.on("navigation.back.requested", async () => {
  const hasInternalHistory = window.history.length > 1;
  // If true, mini app handles back step. If false, host shell exits mini app.
  await sdk.navigation.router.back(hasInternalHistory);
});
```

### `router.push(consumed)`

Notifies the host shell that the mini app pushed an internal route step.

- **Signature**: `router.push(consumed?: boolean): Promise<NavigationRouterResult>`

```typescript
await sdk.navigation.router.push(true);
```

## Deep links into your mini app

A citizen can arrive already pointed at a screen: from a push notification, or
from another mini app. Sewa passes that as `runtime.initialPath` when it calls
your `mount`:

```js
export function mount(container, runtime) {
  const startAt = runtime?.initialPath ?? "/";
  router.replace(startAt);
}
```

`initialPath` is a path inside **your** app, the same shape your own router
uses. It is absent on a normal open, so always provide a default.

When your backend finishes long-running work it can set `deepLinkIntent` on the
callback, and tapping the notification opens your mini app at that path. See
[Long-running requests](/docs/async-requests).

## Keeping the back button honest

The shell has one back control and your app has its own history. Tell the shell
which of you consumed the press:

```js
sdk.on("navigation.back.requested", async () => {
  if (router.canGoBack()) {
    router.back();
    await sdk.navigation.router.back(true);   // you handled it
  } else {
    await sdk.navigation.router.back(false);  // close the mini app
  }
});
```

Answer every time. Staying silent leaves the citizen pressing back with nothing
happening.
