# Navigation Module (`sdk.navigation`)

The `sdk.navigation` module manages platform route transitions and synchronizes internal mini app routers with the host shell back button.

---

## Public Methods

### `navigate(target)`

Requests the host platform to navigate - typically to a route in another mini app.

- **Signature**: `navigate(target: NavigationTarget): Promise<void>`

```typescript
await sdk.navigation.navigate({
  app: "chat-mini-app",
  route: "/",
  params: { purpose: "Want to chat with AI" },
});
```

`NavigationTarget` is `{ app, route, params?, replace? }`. For deep-linking *into* your own mini
app from outside, the host passes `{ initialPath }` to your `mount()` - see
[Getting Started](/docs/getting-started) and [Links](/docs/sdk/links).

### `getCurrent()`

Queries current navigation state from the host.

- **Signature**: `getCurrent(): Promise<NavigationState>`

```typescript
const navState = await sdk.navigation.getCurrent();
console.log("Current route:", navState.current);
```

### `router.back(consumed)`

Reports whether the mini app internal router handled a back-press or wants the host to exit the mini app container.

- **Signature**: `router.back(consumed?: boolean): Promise<NavigationRouterResult>`

```typescript
sdk.on("navigation.back.requested", async () => {
  // Derive from your own router ("am I at root?"), not window.history -
  // the host owns browser history. Guard with ?. : some mobile hosts don't
  // implement the router bridge, and absence must not crash rendering.
  const consumed = currentPath !== "/";
  await sdk.navigation.router?.back?.(consumed);
  if (consumed) goBackOneStep();
});
```

See the framework guides ([React](/docs/integration/react), [Vue](/docs/integration/vue),
[Svelte](/docs/integration/svelte), [Solid](/docs/integration/solid)) for the full bidirectional
sync pattern: emit `navigation.route.changed` with root-derived `canGoBack` on every route change.

:::warning Raw hash writes
Never navigate by assigning `location.hash` - in Chrome this fires a spurious `popstate` that the
host shell mistakes for a back press (see the [Svelte guide](/docs/integration/svelte)). Always
route through your framework router (or `history.pushState` + manual router notification).
:::

### `router.push(consumed)`

Notifies the host shell that the mini app pushed an internal route step.

- **Signature**: `router.push(consumed?: boolean): Promise<NavigationRouterResult>`

```typescript
await sdk.navigation.router.push(true);
```
