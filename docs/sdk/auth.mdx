# Authentication (`sdk.auth`)

Exposes the host's authenticated user to the mini app. Read-only - login itself happens in the host; this module only reports who is signed in and ends the session on request.

---

## Public Methods

### `getUser()`

Returns the currently authenticated user, or `null` when nobody is signed in.

**Signature:** `getUser(): Promise<PlatformUser | null>`

**Returns:** `PlatformUser | null`

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Stable user identifier. |
| `name` | `string` | Display name. |
| `email` | `string` | Email address. |
| `fullName` | `string?` | Full legal name, when the host provides it. |
| `nationalId` | `string?` | National ID, when the host provides it. |
| `roles` | `string[]` | Role codes granted to the user. |
| `permissions` | `string[]` | Fine-grained permission codes. |
| `avatar` | `string?` | Avatar image URL, when available. |

### `isAuthenticated()`

Whether a user is currently signed in. Prefer this for gating UI; use `getUser()` when you need the profile.

**Signature:** `isAuthenticated(): Promise<boolean>`

<CodeTabs
  typescript={`if (await sdk.auth.isAuthenticated()) {
  enableTaxFiling();
}`}
  javascript={`if (await sdk.auth.isAuthenticated()) {
  enableTaxFiling();
}`}
/>

### `logout()`

Ends the host session. The host also emits an auth event so other mini apps can reconcile.

**Signature:** `logout(): Promise<void>`

<CodeTabs
  typescript={`await sdk.auth.logout();
redirectToWelcome();`}
  javascript={`await sdk.auth.logout();
redirectToWelcome();`}
/>
