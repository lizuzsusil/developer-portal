# Deep Links (`sdk.links`)

Opens outbound URLs through the host and receives inbound deep links the host routes into the mini app.

---

## Public Methods

### `open(url, options?)`

Opens a URL. The host decides between in-app view and system browser.

**Signature:** `open(url: string, options?: LinksOpenOptions): Promise<void>`

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `url` | `string` | Yes | - | Absolute URL to open. |
| `options.inApp` | `boolean` | No | `false` | `true` asks the host to open inside the host app instead of handing off to the system browser. |

<CodeTabs
  typescript={`await sdk.links.open("https://revenue.example.gov.np/notice/42", { inApp: true });`}
  javascript={`await sdk.links.open("https://revenue.example.gov.np/notice/42", { inApp: true });`}
/>

### `onOpen(handler)`

Subscribes to inbound deep links the host resolves into this mini app. Returns an unsubscribe function.

**Signature:** `onOpen(handler: (event: LinksOpenedEvent) => void): () => void`

**Event payload (`LinksOpenedEvent`):**

| Field | Type | Description |
|---|---|---|
| `url` | `string` | The deep link URL. |
| `params` | `Record<string, unknown>?` | Query/route params the host extracted, when available. |

<CodeTabs
  typescript={`const unsubscribe = sdk.links.onOpen(({ url, params }) => {
  router.navigate(url, params);
});`}
  javascript={`const unsubscribe = sdk.links.onOpen(({ url, params }) => {
  router.navigate(url, params);
});`}
/>

### `isSupported`

Boolean set at construction from handshake capabilities - `true` when the host negotiated the `links` namespace.

**Signature:** `isSupported?: boolean`

<CodeTabs
  typescript={`if (sdk.links.isSupported) {
  await sdk.links.open(url);
} else {
  window.open(url, "_blank");
}`}
  javascript={`if (sdk.links.isSupported) {
  await sdk.links.open(url);
} else {
  window.open(url, "_blank");
}`}
/>
