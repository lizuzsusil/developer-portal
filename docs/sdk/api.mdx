# Backend API Gateway Module (`sdk.api`)

Call your own backend. You give a method and a path; Sewa routes it to the backend
registered for your mini app, so your frontend never holds its address.

---

## Public Methods

### `request(params)`

Sends a request to your own backend. Sewa routes it for you.

- **Signature**: `request<T = unknown, B = unknown>(params?: ApiRequestParams<B>): Promise<ApiResult<T>>`

```typescript
const response = await sdk.api.request<{ taxDue: number }>({
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: { citizenId: "9921-0012" },
});

console.log("Status:", response.status);
console.log("Tax Due:", response.data.taxDue);
```


---

If the work cannot finish inside one call, your backend answers later instead.
See [Long-running requests](/docs/async-requests).
