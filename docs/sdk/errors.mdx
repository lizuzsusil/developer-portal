# Errors

All SDK failures are `SdkError` subclasses carrying a machine-readable `code` and, usually, a `retryable` flag. Branch on the shape - mini apps never import the error classes.

## Hierarchy

```
SdkError
├── HandshakeError        - handshake rejected / timeout / version mismatch
├── TransportError        - transport send/start failure
├── ProtocolError         - malformed wire message
├── TimeoutError          - per-request timeout (retryable)
├── RequestCancelledError - AbortSignal aborted
├── StreamCancelledError  - StreamBuilder.cancel()
├── HttpClientError       - mapped 4xx from proxied HTTP (not retryable)
└── HttpServerError       - mapped 5xx from proxied HTTP (retryable)
```

## Codes

| Code | Meaning | Retryable | Typical source |
|---|---|---|---|
| `HANDSHAKE_FAILED` | Host rejected or never answered the handshake | No | `sdk.initialize()` |
| `CAPABILITY_NOT_SUPPORTED` | Namespace the host did not grant - gate with `isSupported()` / `sdk.capabilities` first | No | Any namespaced call |
| `SDK_NOT_INITIALIZED` | Call before `initialize()` resolved | No | Any call |
| `SDK_ALREADY_DESTROYED` | Call after `destroy()` | No | `initialize()` |
| `INVALID_PARAMS` | Bad call shape (e.g. removed object form, non-relative endpoint) | No | `sdk.request`, host validation |
| `TIMEOUT` | Per-request timeout elapsed | Yes | Any call |
| `REQUEST_CANCELLED` | `AbortSignal` aborted | No | Unmount / user cancel paths |
| `STREAM_CANCELLED` | `StreamBuilder.cancel()` | No | Stream teardown |
| `CIRCUIT_OPEN` | Circuit breaker open under load | After backoff | Any call |
| `HTTP_CLIENT_ERROR` | Mapped 4xx from a proxied HTTP response | No | `api.request` |
| `HTTP_SERVER_ERROR` | Mapped 5xx from a proxied HTTP response | Yes | `api.request` |
| `AUTH_FAILED` / `AUTH_REQUIRED` / `UNAUTHENTICATED` / `FORBIDDEN` | Auth-family failures | No | `sdk.auth`, guarded endpoints |

## Guards

```typescript
try {
  await sdk.auth.getUser();
} catch (err) {
  const code = (err as { code?: string } | null)?.code;
  const retryable = (err as { retryable?: boolean } | null)?.retryable === true;
  if (code === "REQUEST_CANCELLED" || code === "STREAM_CANCELLED") return; // unmount path
  if (code === "TIMEOUT" || retryable) { /* retry or show spinner */ }
  console.log(code); // string | undefined
}
```

`CAPABILITY_NOT_SUPPORTED` is thrown when the mini app calls a namespace the host did not grant during handshake - gate such calls with the module's `isSupported()` (or `sdk.capabilities`) first.
