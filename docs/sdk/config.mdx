# Configuration (`sdk.config`)

Reads host-provided configuration values - backend URLs, feature flags, environment names. Values are resolved lazily by the host on each call, so late-arriving manifests are picked up without re-initializing.

---

## Public Methods

### `get(key)`

Reads a single config value. Resolves to `undefined` when the host has no such key.

**Signature:** `get<T = unknown>(key: string): Promise<T | undefined>`

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `key` | `string` | Yes | - | Config key, e.g. `"apiBaseUrl"`, `"environment"`, `"currency"`. |

<CodeTabs
  typescript={`const baseUrl = await sdk.config.get<string>("apiBaseUrl");
const env = (await sdk.config.get<string>("environment")) ?? "production";`}
  javascript={`const baseUrl = await sdk.config.get("apiBaseUrl");
const env = (await sdk.config.get("environment")) ?? "production";`}
/>

### `getAll()`

Reads the full config map in one round trip.

**Signature:** `getAll(): Promise<Record<string, unknown>>`

**Returns:** `Record<string, unknown>` - object with all config key-value pairs

<CodeTabs
  typescript={`const config = await sdk.config.getAll();
console.log(config.environment, config.locale);`}
  javascript={`const config = await sdk.config.getAll();
console.log(config.environment, config.locale);`}
/>

### Usage Patterns

**Read with fallback:**

<CodeTabs
  typescript={`const baseUrl = (await sdk.config.get<string>("apiBaseUrl")) ?? "https://api.example.com";
const env = (await sdk.config.get<string>("environment")) ?? "production";`}
  javascript={`const baseUrl = (await sdk.config.get("apiBaseUrl")) ?? "https://api.example.com";
const env = (await sdk.config.get("environment")) ?? "production";`}
/>

**Read typed config:**

```typescript
interface AppConfig {
  apiBaseUrl: string;
  environment: string;
  currency: string;
  locale: string;
}

const config = await sdk.config.getAll() as AppConfig;
console.log(config.currency); // "NPR"
```

**Fetch multiple values:**

<CodeTabs
  typescript={`const [baseUrl, env, currency] = await Promise.all([
  sdk.config.get<string>("apiBaseUrl"),
  sdk.config.get<string>("environment"),
  sdk.config.get<string>("currency"),
]);`}
  javascript={`const [baseUrl, env, currency] = await Promise.all([
  sdk.config.get("apiBaseUrl"),
  sdk.config.get("environment"),
  sdk.config.get("currency"),
]);`}
/>
