# Chat Modules Overview

:::info Migration Notice
The previous `sdk.ai` namespace has been removed. Chat functionality is now split into two dedicated modules:

| Module | Purpose | Namespace |
|---|---|---|
| `sdk.http` | Generic LLM chat streaming | `HTTP.CHAT_STREAM` |
| `sdk.gicChat` | GIC-specific agent chat (tool calls, SSE events) | `GIC_CHAT.STREAM` |

Both modules are gated by the **`http`** capability during handshake.
:::

---

## Generic Chat (`sdk.http.stream`)

Streams a generic LLM completion through the host network proxy. Use this for general-purpose AI chat that does not require GIC-specific tool calling or SSE event types.

```typescript
import { ChatMessages } from "@lizuz/mini-app-sdk";

const stream = sdk.http.stream({
  messages: [
    ChatMessages.system("You are a helpful government tax assistant."),
    ChatMessages.user("How do I renew my vehicle tax?"),
  ],
});

for await (const chunk of stream.iterate()) {
  appendToUI(chunk);
}
```

See the full [HTTP Module reference](/docs/sdk/http) for more details.

---

## GIC Chat (`sdk.gicChat`)

Streams responses from the GIC Chat Agent, which supports tool calls (knowledge-base lookups), structured SSE events, and session management. Use this when you need the GIC-specific agent features.

```typescript
// 1. Start a session
const session = await sdk.gicChat.startSession();

// 2. Stream a response
const { invocation_id } = await sdk.gicChat.stream(
  {
    user_id: session.user_id,
    session_id: session.session_id,
    message: "How do I apply for a National Identity Card?",
  },
  {
    onEvent: (event) => {
      switch (event.type) {
        case "tool_call":
          showSearching();
          break;
        case "token":
          appendText(event.text);
          break;
        case "done":
          finalize();
          break;
        case "error":
          showError(event.detail);
          break;
      }
    },
  }
);
```

See the full [GIC Chat Module reference](/docs/sdk/gic-chat) for SSE event details and the `streamText` convenience method.
