# Chat streaming

Chat is part of `sdk.http`. There is no separate chat namespace: a chat
response is an HTTP stream, so it uses the same transport, error mapping and
cancellation as every other `sdk.http` call, and is covered by the same
**`http`** capability.

## Streaming a conversation

```typescript
import { ChatMessages } from "@govtech/mini-app-sdk";

const stream = sdk.http.stream({
  messages: [
    ChatMessages.system("You are a helpful government assistant."),
    ChatMessages.user("How do I renew my vehicle tax?"),
  ],
});

for await (const chunk of stream.iterate()) {
  appendToUI(chunk);
}
```

## Session-scoped turns

Some agent backends keep conversation state server-side and expect a session
identifier rather than the full message list. Pass that shape instead:

```typescript
const stream = sdk.http.stream(
  { user_id, session_id, message: "How do I apply for a NIC?" },
  { onEvent: (event) => render(event) },
);

await stream.waitUntilDone();
```

`onEvent` consumes the stream, so use either `onEvent` or `iterate()` — not
both. A single stream has one consumer.

## Cancelling

```typescript
const controller = new AbortController();
const stream = sdk.http.stream({ messages }, { signal: controller.signal });

controller.abort(); // rejects with StreamCancelledError
```

See [Streaming](/docs/sdk/stream) for `StreamBuilder`, chunk ordering and
progress, and [Errors](/docs/sdk/errors) for the error hierarchy.
