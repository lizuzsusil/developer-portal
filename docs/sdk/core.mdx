# Core SDK & Lifecycle

> **Host-injected, not installed.** In production mini apps the SDK is **injected by the host** at `window.__GSA_SDK__` - see [Getting Started](/docs/getting-started). The host loads the `@lizuz/sewa-sdk` bundle itself (CDN `<script>`); mini apps never install or import the SDK runtime. The instance exposes the lifecycle, capability, and introspection APIs documented here. Direct construction (`new MiniAppSdk(...)` / `createMiniAppSdk`) is host-shell and test-harness only.

---

## Instance

<CodeTabs
  typescript={`// Production - read the injected instance (this is the only form mini apps use)
const sdk: MiniAppSdk = window.__GSA_SDK__;`}
  javascript={`// Production - read the injected instance (this is the only form mini apps use)
const sdk = window.__GSA_SDK__;`}
/>

`sdk.capabilities: string[]` - granted namespaces. `sdk.capabilityVersions`, `sdk.traceId`, `sdk.hostDescriptor`, `sdk.version`.

`getMiniAppSdk()` / `initMiniAppSdk()` are legacy helpers that operate on the active global instance - prefer reading `window.__GSA_SDK__` directly as shown in [React Guide](/docs/integration/react).
