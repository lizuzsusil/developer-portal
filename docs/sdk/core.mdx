# Core SDK & Lifecycle

In production mini apps the SDK is **injected by the host** at `window.__GSA_SDK__` — see [Getting Started](/docs/getting-started). The instance itself exposes lifecycle, capability, and introspection APIs documented here. Direct construction via `@lizuz/mini-app-sdk` is for testing and host shells.

---

## Instance

```typescript
// Production — read the injected instance
const sdk: MiniAppSdk = window.__GSA_SDK__;

// Testing / host shell — direct construction
import { createMiniAppSdk } from "@lizuz/mini-app-sdk";
const sdk = createMiniAppSdk({ miniAppId: "water-bill-app", timeout: 8000 });
await sdk.initialize(); // handshake + hydration
```

`sdk.capabilities: string[]` — granted namespaces. `sdk.capabilityVersions`, `sdk.traceId`, `sdk.hostDescriptor`, `sdk.version`.

`getMiniAppSdk()` / `initMiniAppSdk()` are legacy helpers that operate on the active global instance — prefer reading `window.__GSA_SDK__` directly as shown in [React Guide](/docs/integration/react).

## Event Bus

Covered in detail in [Events](/docs/sdk/events). Quick reference:

```typescript
const off = sdk.on("appearance.theme.changed", (payload) => { /* ... */ });
await sdk.once("navigation.back.requested");
for await (const p of sdk.events("connection.lost")) { /* ... */ }
await sdk.emit("myapp.ready", { version: "1.2.0" });
sdk.addEventInterceptor((event, payload) => payload);
```

## RPC Escape Hatches

See [RPC](/docs/sdk/rpc) for full options.

```typescript
await sdk.request<T>("auth", "getUser");
await sdk.requestSafe<T>("storage", "get", { key: "draft" });
await sdk.batch([{ namespace: "storage", action: "get", payload: { key: "a" } }]);
```

## Middleware

See [RPC](/docs/sdk/rpc) and [Plugins](/docs/sdk/plugins).

```typescript
sdk.use(async (ctx, next) => {
  const t = Date.now();
  const res = await next();
  console.log(`${ctx.namespace}.${ctx.action} ${Date.now() - t}ms`);
  return res;
});
```

## Telemetry

See [Observability](/docs/sdk/observability).

```typescript
sdk.getMetrics();        // totals + per-action percentiles
sdk.debug.snapshot();    // full health dump
sdk.debug.diagnose();    // Diagnostic[] with codes
```
