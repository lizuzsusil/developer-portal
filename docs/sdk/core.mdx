# Core SDK & Lifecycle

> **Host-injected, not installed.** In production mini apps the SDK is **injected by the host** at `window.__GSA_SDK__` - see [Getting Started](/docs/getting-started). The host loads the required SDK bundle itself via CDN, mini apps never install or import the SDK runtime. The instance exposes the lifecycle, capability, and introspection APIs documented here.
