# Protocol & Handshake

> **Background reading for vendors.** The handshake, wire envelope, and version constants below are
> owned by the host and the SDK. What vendors need from this page: the SDK performs a handshake
> carrying your `miniAppId` and requested capabilities, and calls to namespaces the host did not
> grant throw `CAPABILITY_NOT_SUPPORTED` (see [Errors](/docs/sdk/errors)).

## Constants

| Constant | Value | Purpose |
|---|---|---|
| `PROTOCOL_VERSION` | `1.0.0` | Wire format version. Major bumps are breaking. |
| `MESSAGE_CHANNEL` | `gov-platform-sdk` | Filters SDK traffic from unrelated `postMessage`s. |
| `SDK_GLOBAL_KEY` | `__SEWA_SDK__` | `window` key the host writes and the SDK overwrites with the live instance. |

## Wire Shape - `PlatformMessage`

```typescript
interface PlatformMessage<TPayload = unknown> {
  channel: string;
  requestId: string;
  type: "request" | "response" | "event" | "handshake" | "stream";
  namespace: string;
  action: string;
  source: string;
  target: string;
  gsaProtocolVersion: string;
  traceId: string;
  timestamp: number;
  payload?: TPayload;
  error?: { code: string; message: string; retryable?: boolean };
  streamIndex?: number;
  streamTotal?: number;
  streamLast?: boolean;
}
```

`createMessage()` stamps `channel`, `protocolVersion`, `traceId`, and `timestamp`. `isValidPlatformMessage` / `hasCompatibleMajorVersion` guard inbound traffic.

## Handshake

On first `sdk.auth.getUser()` (or any capability call) the SDK sends a `handshake` message:

```typescript
interface HandshakePayload {
  miniAppId: string;
  sdkVersion: string;
  protocolVersion: string;
  protocolVersionRange?: string;
  capabilities: readonly string[];
}

interface HandshakeAckPayload {
  status?: "ok" | "rejected";
  reason?: string;
  protocolVersion?: string;
  supportedVersions?: readonly string[];
  capabilities?: readonly string[] | Record<string, string>;
}
```

- `status: "rejected"` or a major version mismatch throws `HandshakeError`.
- The granted `capabilities` list gates every subsequent `sdk.*` call - see [Errors](/docs/sdk/errors) for `CAPABILITY_NOT_SUPPORTED`.
- `initialize()` is idempotent; concurrent callers share the same handshake promise.
