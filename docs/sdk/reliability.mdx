# Reliability

> **Platform internals.** This page describes how the SDK and the Sewa shell
> talk to each other. You do not need any of it to build a mini app — see
> [Getting Started](/docs/getting-started) for that. It is here for people
> working on the shell or the SDK itself.

Heartbeat, circuit breaker, and adaptive timeout keep the mini app resilient against host stalls.

## Heartbeat

```typescript
// Passed via MiniAppSdkOptions (or rely on defaults)
{
  heartbeat: {
    intervalMs: 30000,  // ping every 30s
    timeoutMs: 5000,    // expect pong within 5s
    maxMissedPongs: 2,  // → connection.lost after 2 misses
  }
}
```

Events: `connection.lost` / `connection.established` - see [Events](/docs/sdk/events). On `lost`, the SDK re-handshakes with backoff; on `established`, queued work resumes.

## Circuit Breaker

```typescript
{
  reliability: {
    circuitBreaker: { threshold: 5, windowMs: 10000, openMs: 30000 }
  }
}
```

States: `closed → open → halfOpen`. While `open`, requests throw `CIRCUIT_OPEN` without hitting the transport.

## Adaptive Timeout

```typescript
{
  reliability: {
    adaptiveTimeout: { enabled: true, factor: 1.5, minMs: 1000, maxMs: 15000 }
  }
}
```

`AdaptiveTimeout` observes observed durations and proposes adjusted timeouts per action.
