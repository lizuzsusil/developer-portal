# Interactive SDK Playground

The explorer below is part of the portal itself - a live documentation widget in `packages/sdk-playground` that lets you test any public SDK method, inspect parameter shapes, and copy code snippets. It is not a standalone installable package; it runs here as a documentation aid.

- **Modules covered:** `auth`, `permissions` (deprecated), `flags`, `config`, `navigation`, `storage`, `platform`, `device`, `http` (incl. `chatStream`), `gicChat`, `appearance`
- **Source:** `packages/sdk-playground/src/SDKExplorer.tsx` inside the portal monorepo
- **Design tokens:** `packages/design-tokens/tokens.css`
